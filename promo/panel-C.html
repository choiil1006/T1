사진 자리완성품 또는 제작 과정 사진
동작설명OPERATION
화면의 화살표가 판정선에 닿는 순간 해당 발판을 밟는다
발판 아래 로드셀이 체중 변화를 감지해 게임에 입력된다
판정과 콤보에 따라 발판 조명과 점수 램프가 켜진다
작동원리PRINCIPLE
발판마다 로드셀 4개와 HX711 모듈로 밟는 압력을 측정
Raspberry Pi Pico가 눌림을 판정해 USB 키보드 신호로 게임에 입력
Mitsubishi FX3U PLC로 발판 LED와 점수 램프를 제어
알루미늄 프로파일 프레임과 PC 판으로 사람의 체중을 지지
제작후기REVIEW
최원준처음 시도해보는 로드셀 제어를 이용한 프로젝트를 제작하면서 사람의 체중을 어떻게 안전하게 받을 수 있을지, 조그만 기판들을 어떻게 연결하여 입력과 출력을 전달할 수 있을지와 같은 난이도 있는 과제와 부딪혀 보면서 3학년의 마지막을 제대로 불태운 것 같아서 만족스럽습니다.
우성민게임 화면과 발판, PLC 조명이 하나의 신호로 이어지도록 맞춰 가는 과정이 생각보다 훨씬 까다로웠습니다. 값이 튈 때마다 선을 다시 잇고 숫자를 다시 읽던 시행착오 끝에, 처음으로 발판을 밟자 화면에 입력이 들어오고 불이 켜졌을 때의 짜릿함은 잊지 못할 것 같습니다. 친구와 끝까지 완성해 낸 이 작품이 고등학교 3년의 가장 큰 자랑으로 남을 것 같습니다.
