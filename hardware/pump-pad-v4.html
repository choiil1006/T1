v3에서 바뀐 점

센서: 로드셀 → 마이크로스위치

발판마다 네 모서리에 소형 레버 마이크로스위치를 달고 병렬로 묶어 신호선 하나로 만듭니다. 영점·감도·HX711 개조가 모두 없어지고, 판정 지연은 약 3~5ms(추정)입니다. v3 로드셀 방식은 샘플 간격만 12.5ms이고 필터 안정까지 더 걸립니다.

Pico는 스위치 5개를 GPIO로 읽어 USB 키보드(넘패드 1·7·5·9·3)로 Pi 5에 보냅니다. step-five 기본 키 매핑과 같아서 게임 코드를 고치지 않아도 되고, 이벤트로 바로 들어와 게임패드 방식의 프레임 폴링 지연(최대 약 16ms)도 없습니다.

기구부에서 달라진 점

  • 로드셀 자리에 압축 스프링(발판을 받침)과 마이크로스위치가 들어갑니다. 발판은 스프링 위에 떠 있다가 약 0.5mm 눌리면 스위치가 닫히고, 1.0mm에서 레일에 닿는 하드스톱은 v3와 같습니다.
  • 코너 플레이트(K1)는 그대로 둡니다. 스프링 윗면과 스위치 레버가 닿는 면 역할을 합니다.
  • K2는 L브래킷에서 스위치 마운트로 이름만 바뀌고, 로드셀 Ø16 구멍 대신 스위치 나사 구멍을 뚫습니다. 길이는 45에서 40으로 줄입니다.
  • HX711 기판과 4심 차폐선이 빠지고, 발판 아래에는 WAGO 레버 커넥터 두 개(GND, 신호)만 둡니다. 케이블은 2심입니다.
  • PLC(FX3U-32MT, 싱크 출력)는 조명과 나중의 모터 확장을 맡습니다. 판정용 입력은 PLC를 거치지 않고, 같은 신호를 Pico가 옵토 모듈로 PLC에 복사해 줍니다. 자세한 구조는 PLC 연동에 있습니다.

3D 모델

드래그해서 돌리고, 두 손가락이나 휠로 확대합니다. 분해도를 켜면 발판이 층별로 떠오르고, 외장을 끄면 전장 박스 안과 단자대 위치가 보입니다.

PLC 연동

FX3U-32MT 싱크 출력 PLC를 발판 조명에 씁니다. 모터는 아직 정하지 않아서 입출력 자리만 비워 둡니다. 발판 판정은 PLC를 거치지 않습니다. PLC 입력은 보통 약 10ms 필터와 스캔 주기가 있어서 판정용 경로로는 느리기 때문입니다. 대신 Pico가 같은 스위치 상태를 옵토 모듈로 PLC에 복사해 주면, PLC는 그 신호로 조명과 모터를 움직입니다.

입출력 배정

  • X10~X14: 발판 좌하·좌상·중앙·우상·우하 (plc/pad-map.json 그대로)
  • X15 전체 점등, X16 조명 끔, X17 모터 예약 (게임이 보내는 명령)
  • X0~X7: 모터 확장용 예약 (원점, 리밋, 엔코더)
  • Y10~Y14: 발판 조명 24V LED, Y15: 캐비닛 조명 예약
  • Y0~Y3: 모터 펄스·방향, Y4: 인에이블 (Y0~Y2가 펄스 출력 가능, 매뉴얼로 확인)

GX Works2에서 명령어 목록으로 입력하거나 같은 내용을 래더로 그리면 됩니다. 밟는 발판은 즉시 켜지고, 게임이 X15를 올리면 전체 점등, X16을 올리면 꺼집니다.

결선 요점

  • 입력 공통 S/S는 +24V에 연결합니다(싱크 입력). 옵토의 트랜지스터가 X를 0V로 끌어내리면 입력이 켜집니다.
  • 출력은 싱크라서 LED 스트립의 +를 24V 전원에, −를 Y 단자에 연결하고, 출력 공통 COM은 24V 전원의 0V에 연결합니다.
  • 점당 0.5A 안팎이 한계입니다(공통 묶음 합계 제한은 매뉴얼 확인). 발판당 LED 스트립은 그 이하로 합니다.
  • 조명 전원은 PLC의 24V 서비스 전원이 아니라 별도 SMPS를 씁니다. 0V만 PLC와 연결합니다.

PLC 설치 위치

  • FX3U-32MT/ES는 폭 약 150, 높이 90, 깊이 약 86mm입니다. 전장 박스(상판 아래 높이 약 35mm)에는 들어가지 않습니다.
  • 본체 밖 뒤쪽 연장부 아래나 옆에 DIN 레일 박스를 따로 달고, Pico와 연결하는 8선 케이블만 본체 안으로 넣습니다.
  • /ES 모델은 AC 100~240V 전원입니다. 220V 배선은 차단기와 접지를 갖춰 박스 안에서만 하고, 자신이 없으면 전기 기사에게 맡기세요.

모터 확장 (미정, 쓰게 되면)

  • 스테핑 드라이버(24V 입력용) + 모터 + 별도 모터용 전원.
  • Y0(펄스), Y1(방향), Y4(인에이블)을 드라이버 입력에 연결합니다. 드라이버 입력이 5V용이면 직렬 저항을 답니다.
  • 원점·리밋 센서는 X0~X2에 연결합니다. 비상정지는 PLC 로직과 별개로 모터 전원을 끊는 하드와이어로 구성하세요.
  • 래더에서 DRVI·ZRN 같은 위치 명령으로 구동합니다. 게임은 Pico 시리얼로 X17 명령 비트를 올리기만 합니다.

게임 쪽 작업 (아직 없음)

  • step-five는 지금 PLC 명령을 보내지 않습니다. Web Serial로 Pico에 1바이트를 쓰는 모듈을 추가해야 합니다.
  • 바이트의 하위 3비트가 X15·X16·X17 상태가 됩니다(예: 1 = 전체 점등, 2 = 조명 끔).
  • Web Serial은 Chromium에서 localhost나 https에서만 쓸 수 있고, 사용자 클릭으로 포트를 한 번 승인해야 합니다.

조명은 스위치가 눌린 뒤 옵토, PLC 입력 필터, 스캔, 출력을 거쳐 켜져서 판정 입력보다 수 ms~십수 ms 늦습니다. 불빛 용도에서는 문제없지만, 이 신호로 판정하지 마세요.

이번 단계 부품이미 단 부품

1바닥 프레임 조립

준비: 육각렌치, 3030 코너 브래킷 32개, 줄자, 직각자, 수평계

  1. F1 두 개를 바닥에 877mm 간격(바깥 기준)으로 평행하게 놓습니다.
  2. F2 네 개를 z −105, 15, 862, 1,112 위치에 코너 브래킷으로 연결합니다. 볼트는 손으로 돌아가지 않을 정도로만 가조임합니다.
  3. F3 두 개를 x 298, 579에 넣어 발판 앞뒤 F2 사이를 잇습니다.
  4. F4 여섯 개(좌우 z 358, 438, 519)와 F5 네 개(z 150, 299, 578, 715)를 위치표대로 연결합니다.
  5. 발판 영역(z 0~877)의 두 대각선 길이 차가 1mm 이내가 되도록 두드려 맞춘 뒤 본조임합니다.
  6. 조절발 16개를 프레임 바닥 슬롯에 달고, 설치할 자리에서 수평계로 네 모서리와 가운데 수평을 맞춥니다.

확인: 대각선 차 1mm 이내, 수평계 기포 중앙, 모서리를 눌러도 흔들림 없음

참고: 프레임 평면도와 부재 위치

2스위치 마운트, 스프링, 가이드 장착

준비: 마이크로스위치 20개, K2 마운트 20개, 압축 스프링 20개, POM 가이드 20개, 캘리퍼스, 멀티미터, 필러 게이지 0.5·1.0mm, 금속 자

  1. 스위치마다 나사 구멍 간격을 캘리퍼스로 재서 K2 윗면에 M2.5 구멍(슬롯)을 뚫고, 스위치를 가조임합니다. 레버가 위를 향하고 레버 끝이 발판 안쪽으로 오게 합니다.
  2. 멀티미터 도통 모드로 COM–NO가 레버를 손으로 누를 때만 닫히는지 스위치 20개 모두 확인하고, 이상이 있는 것은 여유 4개로 교체합니다.
  3. K2를 레일 옆면 T슬롯에 M6 T너트로 가조임합니다. 마운트 윗면이 레일 윗면보다 7mm 낮고, 스프링 중심은 발판 모서리에서 안쪽으로 약 39mm, 스위치는 그보다 레일 쪽(바깥)에 놓입니다.
  4. 스프링을 K2 윗면 스프링 자리에 올립니다. 스프링 높이가 8mm 틈보다 1mm 안팎 높도록 하고, 낮으면 아래에 와셔나 고무 시트를 깝니다.
  5. 금속 자를 레일 윗면에 걸치고 스프링 윗면과 자 사이가 1.0~1.5mm 위가 되는지 봅니다. 높이가 모서리마다 다르면 스프링이나 심으로 맞춥니다.
  6. POM 가이드를 발판 각 변에 하나씩, 모서리에서 90~110mm 지점의 레일 윗면에 고정합니다.

확인: 스위치 20개 모두 레버를 누를 때만 도통하고, 스프링 윗면 높이 편차 ±0.3mm 이내

참고: 단면 A-A, 모서리 평면 상세, 스위치 마운트 부품도

3발판 결선

준비: WAGO 5구 커넥터 10개, 실리콘 전선, 2심 케이블, 인두기(선택), 멀티미터

  1. 발판마다 WAGO 커넥터 둘(GND, 신호)을 레일 옆면에 케이블 타이나 양면테이프로 고정합니다.
  2. 스위치 COM 4개를 GND 커넥터에, NO 4개를 신호 커넥터에 전선으로 연결합니다. 전선은 스위치 쪽에서 레일 따라 짧게 끝내고 발판 영역 밖으로 나가지 않게 합니다.
  3. 2심 케이블의 한 선을 GND 커넥터에, 다른 선을 신호 커넥터에 넣습니다. 케이블 색과 발판 이름을 라벨로 붙입니다.
  4. 케이블은 조절발로 생긴 바닥 틈을 따라 전장 박스까지 보냅니다. 끝에는 20cm 여유를 남깁니다.
  5. 케이블 끝에서 도통을 재면서 스위치 네 개를 하나씩 눌러 신호–GND가 닫히는지 봅니다.

확인: 발판마다 네 모서리 중 어느 스위치를 눌러도 케이블 끝에서 도통, 모두 뗐을 때 개방, 케이블이 프레임 아래에서 눌리지 않음

참고: 발판 결선도, 배선 경로도

4전장부 조립과 1차 동작 확인

준비: 전장판, Pi 5와 쿨러, Pico, M2.5 스페이서, 고무 그로밋, USB 케이블, 컴퓨터(펌웨어 업로드용)

  1. 전장판에 케이블 구멍을 뚫고 고무 그로밋을 끼웁니다.
  2. Pi 5(액티브 쿨러 장착)와 Pico를 M2.5 스페이서로 전장판에 고정하고, 전장판을 앞쪽 프레임 위에 올립니다.
  3. 컴퓨터에서 Pico에 펌웨어(hardware/pico-pad/pico-pad.ino)를 올립니다.
  4. 발판 케이블 다섯 가닥을 핀 배정표대로 Pico에 연결하고 Pico를 USB로 Pi 5에 연결합니다.
  5. 메모장이나 터미널을 열고 발판 스위치를 손으로 눌러 1, 7, 5, 9, 3이 찍히는지 봅니다. 발판을 덮기 전에 여기서 다 잡아야 나중에 다시 뜯지 않습니다.

확인: 다섯 발판 모두 눌리는 동안 해당 숫자가 찍히고, 떼면 멈춤. 다른 발판 숫자가 같이 찍히지 않음

참고: 발판 → Pico 배선도, 핀 배정표, 전장 박스 배치

5캐리어 조립과 올리기, 눌림 지점 맞추기

준비: 2020 프로파일, 2020 L브래킷, 코너 플레이트 20개, M5 접시머리 볼트, 필러 게이지, 멀티미터

  1. 캐리어 다섯 개를 조립도대로 짭니다. 모서리 발판용은 옆변 337, 중앙용은 옆변 277입니다.
  2. 대각선을 재서 직각을 맞추고, 코너 플레이트 네 개를 캐리어 아래에 M5 접시머리로 고정합니다.
  3. 캐리어를 올려 코너 플레이트가 스프링 위에 앉고 스위치 레버가 플레이트 아래면 쪽에 오게 합니다.
  4. 캐리어와 POM 가이드 사이가 사방 1mm 정도인지, 캐리어가 레일이나 옆 부품에 닿지 않는지 확인합니다.
  5. Pico를 연결한 상태에서 캐리어 모서리를 천천히 눌러 숫자가 찍히는 지점을 찾습니다. 플레이트가 0.4~0.6mm 내려갔을 때 찍히고, 1.0mm에서 레일에 닿도록 스위치 아래 심(0.2~0.5mm)이나 스프링 높이를 조정합니다.
  6. 모서리를 체중으로 눌러 레버가 끝까지 눌리기 전에 코너 플레이트가 레일 윗면에 먼저 닿는지 확인합니다.

확인: 빈 캐리어 상태에서 아무 입력도 찍히지 않고, 네 모서리와 가운데 어디를 눌러도 입력이 나오며, 뗄 때 되돌아옴

참고: 캐리어 조립도, 코너 플레이트 부품도

6스페이서와 상판 데크

준비: 스페이서 블록 20개, M6 탭, 상판 데크, M6 접시머리 볼트 20개, 2mm 판

  1. 스페이서 블록 위에 M6 탭을 내고 가공도 위치대로 프레임에 고정합니다.
  2. 상판 데크를 올려 발판 구멍 다섯 개가 캐리어와 맞는지 먼저 봅니다.
  3. M6 접시머리 볼트로 데크를 스페이서에 고정합니다.
  4. 2mm 판을 발판 둘레에 한 바퀴 돌려 걸리는 곳이 없는지 확인합니다.

확인: 데크를 밟아도 발판 입력이 찍히지 않음 (힘이 새지 않는다는 뜻)

10PLC 연동 (조명, 나중에 해도 됨)

준비: PLC 박스, 절연 모듈, 24V SMPS, LED 스트립 5개, 프로그램 케이블과 GX Works2가 깔린 다른 PC

  2. S/S를 +24V에, 출력 COM을 0V에 연결합니다.
  3. 절연 모듈 출력 8개를 X10~X17에, 모듈 전원 공통은 해당 단자 규격대로 연결하고, 모듈 입력은 Pico GP10~GP17과 GND에 연결합니다.
  4. LED 스트립의 +를 SMPS +24V에, −를 Y10~Y14에 연결합니다.
  5. 래더를 올리고 Pico를 연결한 상태에서 발판을 밟아 해당 LED가 켜지는지 봅니다.
  6. Pico 시리얼 터미널에서 바이트 1과 2를 보내 전체 점등과 소등이 되는지 봅니다.

확인: 밟는 발판의 LED만 켜지고, X15·X16 명령에 따라 전체 점등·소등이 되며, 판정용 키보드 입력은 영향이 없음

참고: PLC 연동, 핀 배정표

점검과 소프트웨어

점검 항목

  • 스위치 20개 모두 COM–NO가 레버를 누를 때만 도통하는가
  • 발판마다 네 모서리 어디를 눌러도 신호가 나오는가
  • 빈 캐리어와 PC 발판을 얹은 상태에서 입력이 찍히지 않는가
  • 종이 한 장을 발판 둘레로 돌렸을 때 걸리는 곳이 없는가
  • 체중을 실어 뛰었을 때 코너 플레이트가 레버가 끝까지 눌리기 전에 레일에 먼저 닿는가
  • GPIO에 5V나 전원선이 닿지 않았는가
  • 다른 발판을 밟았을 때 이웃 발판 입력이 같이 찍히지 않는가

Pico 펌웨어

  • 파일: hardware/pico-pad/pico-pad.ino (초안, 실기 미검증)
  • 스위치 5개 → 키보드 + PLC 복사(GP10~GP14)
  • Arduino-Pico 코어에서 USB 스택을 Adafruit TinyUSB로 고릅니다.
  • 눌림은 디바운스 없이 바로, 뗌만 4ms 안정 후에 보냅니다.
  • USB 폴링 간격 1ms, 키는 넘패드 1·7·5·9·3입니다.
  • 같은 USB로 시리얼도 받아 GP15~GP17(PLC 명령)을 켜고 끕니다.
  • CircuitPython은 HID 폴링이 느려서(기본 8ms) 권하지 않습니다.

Pi 5 게임

  • Raspberry Pi OS 64비트의 Chromium으로 step-five를 엽니다.
  • Pico는 키보드로, 인코더는 게임패드로 인식됩니다. 코드 수정은 필요 없습니다.
  • 레인 매핑이 다르면 게임의 키 설정 화면에서 레인을 누르고 발판을 밟아 다시 지정합니다.
  • 오디오는 HDMI나 USB 오디오로 냅니다. 싱크 보정으로 오프셋을 맞춥니다.

PLC (FX3U-32MT)의 자리

  • 판정용 입력은 Pico → USB 키보드로 직접 보냅니다. PLC는 거치지 않습니다.
  • Pico가 같은 상태를 옵토 모듈로 PLC X10~X14에 복사하고, PLC가 래더로 조명(Y10~Y14)을 켭니다.
  • 모터를 달 때는 Y0~Y2 펄스 출력과 X0~X7 입력을 씁니다. 자세한 배정은 PLC 연동.

Pico 펌웨어 초안

// 펌프 발판 v4 - Pico 펌웨어 초안 (실기 미검증)
// 보드: Raspberry Pi Pico (Arduino-Pico 코어), Tools > USB Stack > Adafruit TinyUSB
//
// 하는 일
//  1) 발판 스위치 5개(GP2~GP6) → USB 키보드(넘패드 1·7·5·9·3)  : 판정용, 지연 최소
//  2) 같은 상태를 옵토 모듈로 PLC 입력 X10~X14에 복사(GP10~GP14)   : 조명·모터 로직용
//  3) USB 시리얼로 1바이트(하위 3비트)를 받아 GP15~GP17 → PLC X15~X17 : 게임이 PLC에 보내는 명령
//
// 설계 원칙
//  - 눌림은 디바운스 없이 첫 신호에서 바로 보냅니다 (지연 0).
//  - 뗌만 4ms 동안 안정된 뒤에 보냅니다 (접점 채터링 방지).
//  - USB 폴링 간격 1ms. PLC 쪽 출력은 키보드 보고서를 보낸 뒤에 갱신합니다.
#include <Adafruit_TinyUSB.h>

const uint8_t PIN[5]  = {2, 3, 4, 5, 6};          // 좌하, 좌상, 중앙, 우상, 우하 (DL, UL, CN, UR, DR)
const uint8_t MIR[5]  = {10, 11, 12, 13, 14};     // → PLC X10~X14 (옵토 모듈 입력)
const uint8_t CMD[3]  = {15, 16, 17};             // → PLC X15~X17 (전체 점등, 조명 끔, 모터 예약)
const uint8_t KEY[5]  = {HID_KEY_KEYPAD_1, HID_KEY_KEYPAD_7, HID_KEY_KEYPAD_5, HID_KEY_KEYPAD_9, HID_KEY_KEYPAD_3};
const uint32_t RELEASE_US = 4000;

uint8_t const desc_hid_report[] = { TUD_HID_REPORT_DESC_KEYBOARD() };
Adafruit_USBD_HID usb_hid;

bool     down[5]      = {false, false, false, false, false};
uint32_t highSince[5] = {0, 0, 0, 0, 0};

void sendReport() {
  uint8_t keys[6] = {0, 0, 0, 0, 0, 0};
  uint8_t n = 0;
  for (uint8_t i = 0; i < 5; i++) if (down[i]) keys[n++] = KEY[i];
  while (!usb_hid.ready()) delayMicroseconds(50);
  usb_hid.keyboardReport(0, 0, keys);
}

void setup() {
  for (uint8_t i = 0; i < 5; i++) {
    pinMode(PIN[i], INPUT_PULLUP);                 // 외부 4.7kΩ 풀업을 달면 더 안정적
    pinMode(MIR[i], OUTPUT); digitalWrite(MIR[i], LOW);
  }
  for (uint8_t i = 0; i < 3; i++) { pinMode(CMD[i], OUTPUT); digitalWrite(CMD[i], LOW); }
  Serial.begin(115200);
  usb_hid.setPollInterval(1);
  usb_hid.setReportDescriptor(desc_hid_report, sizeof(desc_hid_report));
  usb_hid.begin();
  while (!TinyUSBDevice.mounted()) delay(1);
}

void loop() {
  bool changed = false;
  uint32_t now = micros();
  for (uint8_t i = 0; i < 5; i++) {
    bool low = (digitalRead(PIN[i]) == LOW);        // 스위치가 닫히면 LOW
    if (low) {
      highSince[i] = 0;
      if (!down[i]) { down[i] = true; changed = true; }          // 눌림: 즉시
    } else if (down[i]) {
      if (highSince[i] == 0) highSince[i] = now ? now : 1;
      else if ((uint32_t)(now - highSince[i]) >= RELEASE_US) {   // 뗌: 4ms 안정 후
        down[i] = false; highSince[i] = 0; changed = true;
      }
    }
  }
  if (changed) {
    sendReport();                                   // 먼저 게임으로
    for (uint8_t i = 0; i < 5; i++) digitalWrite(MIR[i], down[i] ? HIGH : LOW);  // 그다음 PLC로
  }
  while (Serial.available()) {                      // 게임 → PLC 명령: 하위 3비트 = X15, X16, X17
    uint8_t b = Serial.read();
    for (uint8_t i = 0; i < 3; i++) digitalWrite(CMD[i], (b >> i) & 1 ? HIGH : LOW);
  }
}

발판 치수는 공식 규격과 같게 맞춘 DIY 실측 자료 기준입니다. 안전바 높이와 앞뒤 연장부 길이는 제안값이니 키와 설치 공간에 맞게 조정하세요. 스프링 상수와 스위치 눌림 지점(0.4~0.6mm)은 시작값이며 발판 한 장을 먼저 만들어 시험한 뒤 확정하세요.
