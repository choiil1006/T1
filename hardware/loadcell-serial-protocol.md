# 발판 보드 ↔ 게임: 로드셀 명령 규격

게임 설정 화면의 **LOAD CELL** 칸은 발판 보드(HX711을 읽고 USB 키보드 신호를 보내는 마이크로컨트롤러)와 USB 시리얼로 통신합니다. 영점 재설정, 칸별 실시간 값 표시, 칸별 기준값 저장이 모두 아래 명령으로 동작하므로 보드 펌웨어가 이 명령들에 응답해야 합니다.

참고용 펌웨어: [`pad_controller/pad_controller.ino`](pad_controller/pad_controller.ino) — **실제 보드에서 컴파일·검증하지 않은 예시**입니다.

## 통신

| 항목 | 값 |
|---|---|
| 방식 | USB 시리얼(CDC), 115200 baud |
| 형식 | ASCII 한 줄, 끝은 `\n` |
| 칸 순서 | 게임과 같은 DL, UL, CN, UR, DR (번호 0~4) |

보드는 USB 키보드(HID)와 USB 시리얼을 **동시에** 지원해야 합니다. Arduino Leonardo / Pro Micro, Raspberry Pi Pico(arduino-pico 코어), ESP32-S3가 해당됩니다. 브라우저 쪽은 Web Serial을 쓰므로 PC·라즈베리파이의 Chrome/Edge에서만 동작합니다(https 또는 localhost).

## 명령

| 게임 → 보드 | 보드 → 게임 | 의미 |
|---|---|---|
| `TARE` | `OK TARE` | 모든 칸 영점을 다시 잡음 (게임은 4초까지 기다림) |
| `STREAM 1` | `OK STREAM 1` | 실시간 값 보내기 시작 |
| `STREAM 0` | `OK STREAM 0` | 실시간 값 보내기 중지 |
| (STREAM 1 동안) | `V v0 v1 v2 v3 v4 P bbbbb` | 칸별 현재 값(영점 기준)과 눌림 상태(1/0). 초당 25번 정도 |
| `TH?` | `TH on0 off0 on1 off1 … on4 off4` | 칸별 켜짐/꺼짐 기준값 읽기 |
| `TH i on off` | `OK TH i on off` | i번 칸 기준값 저장 (보드가 EEPROM에 보관). 잘못된 값이면 `ERR TH` |

- 게임은 설정 화면에 있을 때만 포트를 열고 실시간 값을 받습니다. 화면을 나가면 `STREAM 0`을 보내고 포트를 닫습니다.
- 영점은 버튼을 누른 뒤 3초 기다렸다가 보냅니다(발을 내릴 시간).
- 보드가 `TH?`·`STREAM`을 지원하지 않으면 게임은 "영점만 사용 가능할 수 있어요"라고 안내합니다.

## 권장 기준값

| | 값 | 근거 |
|---|---|---|
| 켜짐(ON) | 65,000 | 옆 칸 영향(최대 약 30,000)과 직접 밟은 값(약 100,000)의 중간 |
| 꺼짐(OFF) | 45,000 | 옆 칸 영향(30,000)보다 반드시 위 — 옆 칸으로 발을 옮기면 확실히 꺼지도록 |

- 켜짐과 꺼짐 사이는 15,000 이상 벌려 두세요.
- 옆 칸에 점프로 착지할 때 이 칸 값이 50,000을 넘으면 ON을 70,000~75,000으로 올리세요.
- 발끝으로 가볍게 밟았을 때 70,000이 안 나오면 ON을 60,000 정도로 낮추세요.

## 펌웨어에 꼭 들어가야 하는 것

- **HX711 80SPS**: RATE 핀을 HIGH로. 기본 10SPS면 입력이 최대 0.1초 늦습니다.
- **켜짐/꺼짐 기준 분리(히스테리시스)**: 기준선 근처에서 키가 깜빡이지 않게.
- **자동 영점 보정**: 칸이 떼진 상태에서 0 근처일 때 영점이 천천히 따라가게 해서 드리프트를 없앱니다.
- **키는 누르는 동안 유지**: 눌림이면 `Keyboard.press`, 뗌이면 `Keyboard.release` (홀드 노트 때문).
- **영점 잡는 동안 눌린 키 해제**: `TARE` 처리 전에 모든 키를 뗍니다.
