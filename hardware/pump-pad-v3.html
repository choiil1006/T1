전자부 역할 분담

Raspberry Pi 5는 게임을 돌리고, HX711 읽기는 Pico가 전담합니다. Pi 5는 리눅스라 운영체제가 프로그램을 수시로 잠깐 멈추는데, HX711은 클럭 핀이 60µs 넘게 멈추면 절전에 들어가 값이 깨집니다. Pico는 이 일만 하니까 타이밍이 정확하고, Pi 5는 USB 게임패드 두 개(Pico, 인코더)만 받으면 됩니다. 새로 사야 하는 핵심 부품은 Pico 하나입니다.

기구부 보완

  • 조절발 15mm를 달아 바닥 수평을 잡고, 프레임 아래 틈을 배선 통로로 씁니다.
  • 전장 박스를 상판 높이까지 올려 Pi 5와 Pico를 넣습니다.
  • 제로딜레이 인코더는 왼쪽 기둥 바깥 메뉴 버튼 박스에 넣습니다.
  • 상판 받침을 30mm 블록 20개로 통일하고, 측면 고정판 아래 보강재를 한 줄 추가했습니다.
  • POM 가이드를 발판마다 네 변에 하나씩 달아 앞뒤좌우를 모두 잡습니다.

3D 모델

드래그해서 돌리고, 두 손가락이나 휠로 확대합니다. 분해도를 켜면 발판이 층별로 떠오르고, 외장을 끄면 전장 박스 안과 HX711 위치가 보입니다.

3D 모델을 불러오지 못했습니다. 아래 도면에서 같은 구조를 확인할 수 있습니다.

제작 순서

그림에서 주황색이 그 단계에 새로 다는 부품입니다. 발판을 덮기 전에 센서 동작을 먼저 확인하도록 순서를 짰습니다.

미리 준비할 공구

육각렌치 세트(M5, M6, M8), 전동 드릴과 M6 탭, 줄자와 직각자, 수평계, 필러 게이지(0.5, 1.0mm), 멀티미터, 인두기와 수축튜브, 케이블 타이. 3D 프린터가 있으면 로드셀 받침과 버튼 박스를 뽑을 수 있습니다.

이번 단계 부품이미 단 부품

1바닥 프레임 조립

준비: 육각렌치, 3030 코너 브래킷 32개, 줄자, 직각자, 수평계

  1. F1 두 개를 바닥에 877mm 간격(바깥 기준)으로 평행하게 놓습니다.
  2. F2 네 개를 z −105, 15, 862, 1,112 위치에 코너 브래킷으로 연결합니다. 볼트는 손으로 돌아가지 않을 정도로만 가조임합니다.
  3. F3 두 개를 x 298, 579에 넣어 발판 앞뒤 F2 사이를 잇습니다.
  4. F4 여섯 개(좌우 z 358, 438, 519)와 F5 네 개(z 150, 299, 578, 715)를 위치표대로 연결합니다.
  5. 발판 영역(z 0~877)의 두 대각선 길이 차가 1mm 이내가 되도록 두드려 맞춘 뒤 본조임합니다.
  6. 조절발 16개를 프레임 바닥 슬롯에 달고, 설치할 자리에서 수평계로 네 모서리와 가운데 수평을 맞춥니다.

확인: 대각선 차 1mm 이내, 수평계 기포 중앙, 모서리를 눌러도 흔들림 없음

참고: 프레임 평면도와 부재 위치

2로드셀과 가이드 장착

준비: 로드셀 20개, L브래킷 20개, POM 가이드 20개, 멀티미터, 필러 게이지 0.5·1.0mm, 금속 자

  1. 멀티미터로 셀마다 가운데 선을 확인하고, 선에 발판 이름과 번호(예: 좌상-1) 라벨을 붙입니다.
  2. 셀을 L브래킷 위에 올리되 셀 가운데가 Ø16 구멍 위에 오게 하고, 테두리만 3D 프린트 받침이나 에폭시로 고정합니다.
  3. 브래킷을 레일 옆면 T슬롯에 M6 T너트로 가조임합니다. 셀 중심은 발판 모서리에서 가로세로 35mm 안쪽입니다.
  4. 금속 자를 레일 윗면에 걸치고, 셀 돌기와 자 사이가 1.0mm가 되도록 브래킷 아래 심으로 높이를 맞춘 뒤 본조임합니다.
  5. 셀 20개의 선 나오는 방향을 모두 같게 맞춥니다.
  6. POM 가이드를 발판 각 변에 하나씩, 모서리에서 90~110mm 지점의 레일 윗면에 고정합니다.

확인: 셀 20개의 돌기 높이 편차 ±0.2mm 이내

참고: 단면 A-A, 모서리 평면 상세, L브래킷 부품도

3HX711 기판과 센서 배선

준비: HX711 5개, 만능기판 5장, 인두기, 수축튜브, 4심 차폐 케이블

  1. HX711마다 칩 15번 핀(RATE)을 GND에서 떼어 16번 핀(DVDD)에 이어 80SPS로 바꿉니다.
  2. 만능기판에 HX711과 E+, E−, A+, A− 결선 패드를 만들고, 발판 결선도대로 셀 4개를 납땜합니다.
  3. 기판을 각 발판 안쪽 레일 옆면에 고정합니다. 셀의 가는 선은 발판 영역 밖으로 나가지 않게 합니다.
  4. 4심 차폐 케이블(VCC, GND, DT, SCK)을 달고, 조절발로 생긴 바닥 틈을 따라 전장 박스까지 보냅니다. 끝에는 20cm 여유와 발판 이름 라벨을 남깁니다.
  5. 멀티미터로 발판마다 E+–E−, A+–A− 저항을 재서 다섯 발판이 비슷한지 봅니다.

확인: 다섯 발판의 저항값이 서로 비슷함, 케이블이 프레임 아래에서 눌리지 않음

참고: 발판 결선도, 배선 경로도

4전장부 조립과 1차 동작 확인

준비: 전장판, Pi 5와 쿨러, Pico, M2.5 스페이서, 고무 그로밋, USB 케이블

  1. 전장판에 케이블 구멍을 뚫고 고무 그로밋을 끼웁니다.
  2. Pi 5(액티브 쿨러 장착)와 Pico를 M2.5 스페이서로 전장판에 고정하고, 전장판을 앞쪽 프레임 위에 올립니다.
  3. HX711 케이블 다섯 가닥을 핀 배정표대로 Pico에 연결합니다. 전원은 반드시 3V3(36번)에서 받습니다.
  4. Pico를 USB로 Pi 5에 연결하고, 테스트 펌웨어로 각 셀을 손으로 눌러 값이 바뀌는지 시리얼로 확인합니다.
  5. 값이 반대로 움직이는 발판은 A+와 A−를 바꿉니다. 발판을 덮기 전에 여기서 다 잡아야 나중에 다시 뜯지 않습니다.

확인: 다섯 발판 모두 누르면 값이 커지고, 손을 떼면 원래 값으로 돌아옴

참고: HX711 → Pico 배선도, 핀 배정표, 전장 박스 배치

5캐리어 조립과 올리기

준비: 2020 프로파일, 2020 L브래킷, 코너 플레이트 20개, M5 접시머리 볼트

  1. 캐리어 다섯 개를 조립도대로 짭니다. 모서리 발판용은 옆변 337, 중앙용은 옆변 277입니다.
  2. 대각선을 재서 직각을 맞추고, 코너 플레이트 네 개를 캐리어 아래에 M5 접시머리로 고정합니다.
  3. 캐리어를 해당 로드셀 위에 올려 코너 플레이트 접촉점이 셀 돌기에 오게 합니다.
  4. 캐리어와 POM 가이드 사이가 사방 1mm 정도인지, 캐리어가 레일이나 옆 부품에 닿지 않는지 확인합니다.
  5. 캐리어 모서리를 체중으로 눌러 코너 플레이트가 레일 윗면에 먼저 닿는지(하드스톱) 확인합니다.

확인: 빈 캐리어 상태에서 값이 안정적이고, 모서리를 세게 눌러도 셀 값이 포화되기 전에 레일에 닿음

참고: 캐리어 조립도, 코너 플레이트 부품도

6스페이서와 상판 데크

준비: 스페이서 블록 20개, M6 탭, 상판 데크, M6 접시머리 볼트 20개, 2mm 판

  1. 스페이서 블록 위에 M6 탭을 내고 가공도 위치대로 프레임에 고정합니다.
  2. 상판 데크를 올려 발판 구멍 다섯 개가 캐리어와 맞는지 먼저 봅니다.
  3. M6 접시머리 볼트로 데크를 스페이서에 고정합니다.
  4. 2mm 판을 발판 둘레에 한 바퀴 돌려 걸리는 곳이 없는지 확인합니다.

확인: 데크를 밟아도 발판 값이 변하지 않음 (힘이 새지 않는다는 뜻)

참고: 상판 데크 가공도

7안전바와 메뉴 버튼 박스

준비: 4040 기둥 2개, 손잡이, 브레이스 2개, 4040 코너 브래킷, 각도 조인트, 폼 그립, 버튼 박스

  1. 기둥(B1)을 F1 위 z 880~920 위치에 세우고 4040 코너 브래킷을 앞뒤에 하나씩 답니다.
  2. 손잡이(B2)에 폼 그립을 먼저 끼운 뒤 두 기둥 위를 연결합니다.
  3. 브레이스(F6)를 각도 조인트로 기둥 뒷면과 F1 윗면 사이에 겁니다.
  4. 버튼 박스에 30mm 버튼 네 개와 인코더를 넣고 결선한 뒤, 왼쪽 기둥 바깥에 고정합니다.
  5. 인코더 USB 케이블을 기둥 슬롯과 프레임 아래를 거쳐 전장 박스의 Pi 5에 연결하고, 노출된 슬롯은 슬롯 커버로 막습니다.

확인: 손잡이를 앞뒤로 세게 당겨도 흔들리거나 프레임이 들리지 않음

참고: 안전바 측면 상세

8펌웨어, 캘리브레이션, 발판 얹기

준비: PC 발판 5장, 인쇄지와 확산 필름(선택), M5 접시머리 볼트 30개

  1. Pico에 게임패드 펌웨어를 올리고 빈 발판 상태로 영점을 잡습니다.
  2. 10kg 덤벨처럼 무게를 아는 물건으로 발판별 감도를 맞춥니다.
  3. PC 발판 아래에 화살표 인쇄지와 확산 필름을 깔고, M5 접시머리 6개로 캐리어에 고정합니다.
  4. 발판 무게만큼 영점이 바뀌니 다시 영점을 잡고, 실제로 밟으면서 눌림·떼짐 임계값을 조정합니다.
  5. Pi 5에서 게임패드 두 개(Pico, 인코더)가 모두 인식되는지 확인합니다.

확인: 다섯 발판 모두 같은 세기로 반응하고, 빠르게 연타해도 입력이 빠지지 않음

참고: 점검 항목과 소프트웨어

9마감

준비: 측면 커버, 전장 박스 덮개, 슬롯 커버

  1. 좌우와 앞뒤 측면 커버를 프레임 옆 슬롯에 고정합니다.
  2. 쿨러 위치에 환기 구멍을 낸 덮개로 전장 박스를 닫고, 앞면으로 HDMI와 전원 케이블을 뺍니다.
  3. 손이나 발이 닿는 곳의 노출 슬롯과 모서리를 정리합니다.
  4. 아래 점검 항목을 처음부터 끝까지 한 번 더 확인합니다.

확인: 30분 정도 플레이한 뒤 Pi 5 온도와 영점 변화 확인

참고: 정면도, 우측면도

점검과 소프트웨어

점검 항목

  • 로드셀마다 가운데 선을 멀티미터로 확인했는가
  • 발판 다섯 개의 E+–E−, A+–A− 저항이 서로 비슷한가
  • HX711 VCC가 3V3에 연결되어 있는가 (5V 금지)
  • DT 신호 주기가 약 12.5ms인가 (80SPS 개조 확인)
  • 빈 발판에서 값이 안정되고, 밟으면 양수로 커지는가
  • 종이 한 장을 발판 둘레로 돌렸을 때 걸리는 곳이 없는가
  • 체중을 실어 뛰었을 때 코너 플레이트가 레일에 먼저 닿는가

Pico 펌웨어

  • Arduino-Pico 코어로 5버튼 USB 게임패드를 만듭니다.
  • DT 하강 에지 인터럽트로 읽고, 읽는 동안 다른 인터럽트를 막습니다.
  • 빈 발판일 때만 영점을 천천히 따라가고, 눌림·떼짐 임계값을 따로 둡니다.
  • 평균 필터 없이 첫 샘플에서 판정하고, 힘 원시값은 시리얼로 함께 보냅니다.

Pi 5 게임

  • Raspberry Pi OS 64비트에서 Pico와 인코더를 게임패드 두 개로 받습니다.
  • 입력 이벤트 시각으로 판정하고, 오디오·입력 오프셋 보정 화면을 둡니다.
  • Pico 시리얼 값을 보여주는 패널 모니터 화면으로 감도를 조정합니다.
  • 소리는 HDMI나 USB 오디오로 냅니다.
